## Дoмaшнее зaдaние № 4 по Сиcт. дизaйнy

### Разработана информационная система, которая состоит из микросервисов:
 **File Storing Service** – отвечает только за хранение и выдачу файлов;
 **File Analisys Service** – отвечает только за проведение анализа, хранение результатов (отчетов) и выдачу отчетов.
Также реализова **API Gateway**, который будет являться центральным сервисом-посредником, принимающим все запросы от клиентов и маршрутизирующим их к соответствующим микросервисам. 

Реализовано с использованием системы сборки Gradle (многомодульный проект).
Реализован запуск всех компонентов системы через Docker compose.

В задании указано на формат загружаемого файла (допустимый формат (pdf/docx/txt) NOT ZIP), в соответствии с этим принято решение проверять файлы только по расширению.
Проверка файлов по содержимому не происходит, реализация возможна, но требует усложнения проверок.

Для хранения загруженных файлов используется хранилище MinIO, в режиме разработки удобный доступ к хранилищу через веб-интерфейс.

Для хранения данных о загруженных файлах и результатах анализа используется СУБД PostgreSQL (для каждого сервиса своя).

После загрузки файла в File Storing Service данные о загруженном файле сохраняются в БД сервиса,
запускается сервис анализа File Analisys Service, который проверяет размер и расширение файла и 

Доступ к API обоих сервисов реализован через сревис API Gateway.


## Технологии

- Java 17
- Spring Boot 3.5.x
- Spring Cloud Gateway
- Spring Data JPA + Hibernate
- PostgreSQL 16 (Alpine)
- MinIO (S3-совместимое хранилище)
- Resilience4j (Circuit Breaker + Retry)
- SpringDoc OpenAPI 2.8.x (Swagger)
- Docker + Docker Compose
- Gradle
- Lombok
- JUnit 5 + Mockito + MockWebServer
